# 📊 Dashboard Analítico de Vendas Globais com Power BI

## 🎯 Sobre o projeto

Projeto desenvolvido durante minha formação na DSA (Data Science Academy), utilizando o Power BI Desktop para realizar uma análise de vendas globais por meio de indicadores e visualizações interativas.

O dashboard permite explorar o desempenho das vendas considerando diferentes categorias, subcategorias, países, segmentos, períodos e prioridades de entrega.

## 🛠️ Ferramenta utilizada

- Power BI Desktop

## 📈 Indicadores e análises

O dashboard apresenta:

- Total de vendas;
- Total de vendas por categoria;
- Média de desconto por subcategoria;
- Média de vendas por país;
- Vendas realizadas por País e por Prioridade de Entrega;
- Análise por segmento;
- Análise por País;
- Análise por período.

## 📊 Visualizações

Foram utilizadas diferentes visualizações para facilitar a interpretação dos dados:

- Gráfico de barras para análise da média de desconto por subcategoria;
- Gráfico de pizza para distribuição do total de vendas por categoria;
- Cartão para apresentação do total de vendas;
- Mapa para análise da média de vendas por país;
- Gráfico de barras empilhadas para análise da quantidade de pedidos por país e prioridade.

## 🎛️ Interatividade

O relatório possui filtros que permitem explorar os dados sob diferentes perspectivas:

- **Ano;**
- **Segmento:** Consumidor, Corporativo e Home Office;
- **País.**

## 🔎 Principais informações

O dashboard apresenta um total de vendas de aproximadamente **12,64 milhões**.

A análise também permite observar a participação das diferentes categorias no total de vendas, comparar o desempenho entre países e analisar a distribuição dos pedidos de acordo com suas respectivas prioridades de entrega.

Além disso, é possível avaliar a média de desconto aplicada em diferentes subcategorias de produtos.
